# RISKS

| 问题或风险 | 证据 | 状态 / 保护措施 |
|---|---|---|
| 网页创作台里的 AI 写作质量没有在真实页面里验证过 | 所有页面功能只用模拟 AI 测过；真实质量只在 agent 写的集上验证 | 待验证；正式写作走 agent |
| 网页数据只存在用户浏览器里 | localStorage，换浏览器或清缓存就没了 | 让用户经常「导出项目文件」，把 json 存进仓库 |
| 三处质量门阈值可能不一致 | check.py、gate-checker.html、studio.html 各写一份 | 改阈值时三处同步（MAP.md） |
| 剧本第一稿经常写短 | E01、E02 首稿都短于目标，需要修 | screenwriter 先估算时长再交，质量门兜底 |
| 《你欠我一条命》E01（74.5）、E02（74）没到 75 分及格线 | 各自 review.md | 待用户决定是否再改 |
| 《你欠我一条命》E02 开场和新 E01 结尾重复 | E01 v2 已提出交易，E02 又用照片要挟 | E02 已标「需重审」 |
| Claude 缺少设定时自作主张 | 《一口变凡人》概念被自编 | AGENTS.md 已写「缺设定先问」 |
| skill 没有存进用户的 claude.ai 账号 | 之前提议过，用户未保存 | 在本仓库里用 Claude Code 时不受影响 |
